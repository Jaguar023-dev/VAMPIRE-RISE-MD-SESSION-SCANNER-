# 🩸 VAMPIRE RISE MD

**WhatsApp Session Generator** — by **KENYAN JAGUAR**

Connect a WhatsApp account via pairing code or QR code. The application
never sees your WhatsApp password; it only brokers the standard
WhatsApp Web pairing flow via Baileys.

---

## Requirements

- Node.js **20 LTS** or newer
- npm
- A modern browser
- The WhatsApp mobile app

## Run locally

```bash
git clone <your-repo> vampire-rise-md
cd vampire-rise-md
npm install
npm run dev
